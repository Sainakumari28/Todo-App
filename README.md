# Todo App

A simple and user-friendly Todo App built using Node.js, Express.js, MongoDb, EJS.

## Features

- Signup
- Login
- Add new tasks
- Edit tasks
- Delete tasks
- Mark tasks as complete
- Flash success messages
- Data stored in MongoDB Atlas

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS

## Installation

1. Clone the repository.
2. Install dependencies:

```bash
npm install
```

3. Create a `.env` file and add your MongoDB connection string:

```env
ATLASDB_URL=your_mongodb_connection_string
```

4. Run the application:

```bash
node index.js
```

5. Open:

```text
http://localhost:5000/todo
```
